# YMH219-FlappyBird

Windows Forms ile geliştirilmiş Flappy Bird benzeri masaüstü oyunu.

## Kullanılan Teknolojiler
- C# / .NET, Windows Forms (harici NuGet paketi yok)

## Kurulum ve Çalıştırma
1. Depoyu klonlayın.
2. `FlappyBird.sln` dosyasını Visual Studio ile açın.
3. F5 ile çalıştırın.

## Özellikler
- Space ile zıplama, yer çekimi
- Sağdan sola hareket eden ve yeniden konumlanan engeller
- Çarpışma kontrolü ve Game Over
- Skor sayacı, R tuşu veya butonla yeniden başlatma
